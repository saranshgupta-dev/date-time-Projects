# 📅 Date-Time-Projects

A simple and interactive **Date & Time Dashboard** built using HTML, CSS, and JavaScript. This project includes a live digital clock and a delivery date calculator.

## 🌐 Live Demo

[**View Live Project →**](https://date-time-projects.netlify.app/)

## ✨ Features

- Live digital clock with hours, minutes, and seconds.
- Displays current date and weekday.
- 12-hour time format with AM/PM.
- Delivery date calculator.
- Input validation for delivery days (1–365).
- Automatic date calculation and formatting.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Netlify (Deployment)
- Git & GitHub

## 📚 JavaScript Concepts Practiced

- **Date Object:** `new Date()`
- **Getter Methods:** `getHours()`, `getMinutes()`, `getSeconds()`, `getDate()`, `getMonth()`, `getFullYear()`
- **Setter Methods:** `setDate()`, `setHours()`
- **Date Formatting:** `Intl.DateTimeFormat()`
- **DOM Manipulation:** `querySelector()`, `textContent`
- **Events:** `addEventListener()`
- **Timers:** `setInterval()`
- **Validation:** `Number.isInteger()`, conditional statements
- **Operators:** Ternary, logical AND, OR, and NOT
